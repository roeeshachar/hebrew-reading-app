# עולם הקריאה

אפליקציית ווב (PWA) שמלמדת ילד בגיל הגן לקרוא עברית. נבנתה לאייפון, ועובדת גם באנדרואיד ובמחשב.

## מה יש בגרסה הזאת
- **עולם הקריאה**: מסך בית עם תחנות. רק "מה מתחיל ב…?" פעילה, והשאר מסומנות כ"בקרוב".
- **מה מתחיל ב…?**: סבב של 5 שאלות. הצליל מושמע, הילד בוחר תמונה. טעות לא מענישה, ואחרי שתי טעויות האפליקציה מראה את התשובה. התמונות הן אימוג'י זמניים.
- **מעבדת המילים**: פתוחה תמיד, 22 אותיות ו-7 תנועות. כל לחיצה על אות משמיעה אותה, רצף חסר משמעות מתקבל כרגיל, מחיקה מסירה אות עם הניקוד שלה, והאות האחרונה מוצגת בצורה סופית (ם, ן...).
- **שמע**: קליפים מוקלטים אם קיימים, אחרת הקול העברי של המכשיר. אם אין קול עברי מוצגת הודעה והמשחק ממשיך.
- אין חשבון, שרת או אנליטיקה. התקדמות נשמרת רק במכשיר.

## הרצה
```
npm start            # http://localhost:8080
npm test             # בדיקות לוגיקה
npm run test:e2e     # בדיקת דפדפן (דורשת: npm i -D playwright, ו-CHROMIUM=... אם צריך)
```
אין שלב בנייה. הקבצים מוגשים כמו שהם.

## התקנה על האייפון
שירות ה-Service Worker (עבודה בלי רשת) והתקנה למסך הבית דורשים HTTPS. אפשרויות:
1. לפרסם את התיקייה כאתר סטטי (GitHub Pages, Netlify, Cloudflare Pages). זו הדרך המומלצת.
2. לבדיקה מהירה ברשת הביתית: `npm start` ופתיחת `http://<כתובת-המק>:8080` ב-Safari. עובד, אבל בלי התקנה ובלי עבודה אופליין.

ב-Safari: שיתוף ← "הוספה למסך הבית". האפליקציה נפתחת במסך מלא.

## הקלטות
1. `npm run recording-list` יוצר את `docs/recording-list.md`, עם כל קליפ ושם הקובץ שלו.
2. שמרו קבצי mp3 בתיקיית `audio/` לפי השמות שברשימה.
3. `npm run audio-manifest` מעדכן את `audio/manifest.json`. אין שינוי בקוד.

## מה לבדוק על אייפון אמיתי (לא נבדק עדיין)
- האם קיים קול עברי, ואיך הוא מקריא אות בודדת, הברה עם ניקוד ורצף מומצא.
- האם הצליל נשמע כשמתג השקט פעיל, ואחרי שהמסך ננעל והתעורר.
- התנהגות במסך מלא אחרי "הוספה למסך הבית".

## מבנה
```
index.html, styles.css, sw.js, manifest.webmanifest
src/content.js     אותיות, תנועות, מילים, קבוצות צלילים דומים
src/lab-logic.js   רצף אותיות, מחיקה, אותיות סופיות
src/rounds.js      בניית סבב שאלות
src/audio.js       קליפים עם גיבוי לקול המכשיר
src/app.js         מסכים וניווט
tools/             שרת מקומי, רשימת הקלטות, מניפסט שמע
```

## רעיונות להמשך
בונים מילה, מפלצת ההברות, נקודת דגש (בּ/ב), איורים אמיתיים, מסך הורה. ראו את התוכנית המלאה בשיחה המקורית.
