# הקלטות וצלילים

האפליקציה מנגנת קליפ מוקלט אם יש כזה, ואחרת משתמשת בקול העברי של המכשיר. רשימת כל הקליפים ושמות הקבצים נמצאת ב-[recording-list.md](recording-list.md).

## ליצור עם ElevenLabs

1. **בדיקה בלי קוד.** באתר, בוחרים קול ומודל (v4 או v3, ולהשוות), ומקלידים כמה פריטים: הברות (בָ בַ בִ), מילה מנוקדת (דֶּלֶת), רצף מומצא, והוראה. מקשיבים.
2. **מכינים:** מפתח API (בפרופיל), מזהה הקול (Voice ID) ושם המודל (Model ID) מהתיעוד, ו-Node 18 ומעלה.
3. **ניסוי קטן:**
   ```
   export ELEVENLABS_API_KEY=...
   export VOICE_ID=...
   export MODEL_ID=...        # ברירת המחדל eleven_v3
   node tools/generate-audio.mjs --only prompts,sounds --limit 6
   ```
4. **מקשיבים** לקבצים שנוצרו בתיקיית `audio/`. אם קליפ לא טוב, מוחקים את הקובץ ומריצים שוב רק אותו (המערכת מדלגת על מה שקיים). לצלילי אותיות כדאי `--stability 1`.
5. **הכול:** `node tools/generate-audio.mjs`. אפשר גם לפי קבוצות: `--only words`, `--only syllables`.
6. `npm run audio-manifest`, אחר כך commit ו-push. האתר מתעדכן.

## מה נאמר בפועל

- **שמות האותיות** (`--only names`): "דָּלֶת", "בֵּית". בבועות ובמעבדה, כשמחפשים או בוחרים אות.
- **צלילי אותיות** (`--only sounds`): האות עם שווא, למשל דְּ, כי האות לבדה נקראת בשמה ("דלת"). א ו-ע נאמרות עם פתח, כי עם שווא הן שקטות. אפשר לשנות כל אות ב-`SOUND_TEXT` בקובץ `src/content.js`, למחוק את הקליפ ולייצר מחדש.
- **מילים:** עם ניקוד מלא (`WORD_NIKUD`).
- **הברות והוראות:** כפי שהן כתובות.

## להקליט בעצמך במקום

מקליטים כל פריט ברשימה (אפשר בתזכירים קוליים), שומרים כ-mp3 בשם שברשימה בתיקיית `audio/`, ומריצים `npm run audio-manifest`. קליפ מוקלט ידנית ומוקלט ב-ElevenLabs יכולים לשבת יחד.
